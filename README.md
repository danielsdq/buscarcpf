# 🔍 Buscar CPF

> Uma ferramenta desenvolvida para consulta, validação e manipulação eficiente de CPFs, estruturada com foco em boas práticas de engenharia de software e código limpo.

---

## 📋 Sobre o Projeto

O **BuscarCPF** é um projeto utilitário desenvolvido com o objetivo de [Buscar Pessoas em banco de dados pelo numero de CPF, e-mails, nome e data de nascimento além de  realizar consultas em ambiente de testes, etc.]. 

*(Nota: Stack exata Utilizada: Java 21)*

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias e ferramentas:

* **Linguagem:** [Java 21]
* **Testes:** [Mockito / Junit]
